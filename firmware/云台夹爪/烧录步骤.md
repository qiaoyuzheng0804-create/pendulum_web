# STM32F103C8T6 云台程序烧录步骤

## 一、只打开这个工程

双击：

```text
STM32F103C8T6_Keil工程\USER\GIMBAL.uvprojx
```

不要打开 `STM32资料` 中原来的 USART、LED、PWM 示例工程。`GIMBAL.uvprojx` 是云台工程，芯片为 STM32F103C8T6，使用 `startup_stm32f10x_md.s`，并已勾选生成 HEX。

## 二、ST-Link 与开发板连线

在开发板右下角找到丝印为 `SWD` 的排针，按丝印名称连接，不要只按插头方向猜：

| ST-Link | 开发板 SWD端 |
|---|---|
| SWDIO / DIO | DIO（芯片 PA13） |
| SWCLK / CLK | CLK（芯片 PA14） |
| GND | GND |
| 3.3V | 3.3V |

如果 ST-Link 有 `RST/NRST`，可以再接开发板的 `RST/NRST`，普通下载不是必须；连接异常时很有用。

烧录时先断开两个步进驱动器的 24V 电源，并暂时拔掉 USB-TTL。最简单的烧录供电方式是由 ST-Link 的 3.3V 接开发板 3.3V，此时不要再从 USB 或 5V 引脚给开发板供电。ST-Link 只能带开发板，绝不能给电机驱动器供电。

如果你选择用开发板 Micro-USB 或外部 5V 给开发板供电，则不要再连接 ST-Link 的 3.3V，只接 `DIO、CLK、GND`；两边 GND 必须相连。

开发板的启动配置保持正常运行模式：`BOOT0=0`。资料背面的表格中这就是 `FLASH` 模式。

## 三、首次打开 Keil 后检查

1. 双击 `GIMBAL.uvprojx`，等待 Keil 打开。
2. 左侧 Project 窗口应出现目标 `GIMBAL`，并能看到 `USER、HARDWARE、SYSTEM、CORE、FWLIB` 等分组。
3. 点击工具栏的魔术棒图标，或菜单 `Project -> Options for Target 'GIMBAL'`，也可以按 `Alt+F7`。
4. 在 `Device` 页面确认显示 `STM32F103C8`。
5. 在 `C/C++` 页面确认 `Define` 中有：

```text
STM32F10X_MD,USE_STDPERIPH_DRIVER
```

6. 在 `Output` 页面确认勾选 `Create HEX File`。

这些内容工程已经配置好，正常情况下只检查，不要改。

## 四、把下载器改成 ST-Link

1. 保持在 `Options for Target 'GIMBAL'` 窗口。
2. 点击 `Debug` 标签。
3. 选择右侧的 `Use`，在下拉框中选 `ST-Link Debugger`，不要选 Simulator、J-LINK/J-TRACE。
4. 点击 `Use` 右边的 `Settings`。
5. 在 `Debug` 页把 `Port` 设为 `SW`。如果看到 `Max Clock`，第一次设为 `1 MHz` 或更低。
6. 此时右侧应能看到 STM32 设备信息；看到设备 ID 表示 SWD 已连接。
7. 点击 `OK` 返回目标设置窗口。
8. 打开 `Utilities` 标签，勾选 `Use Target Driver for Flash Programming`，下拉框选择 `ST-Link Debugger`。
9. 点击旁边的 `Settings`，进入 `Flash Download` 页面。
10. 勾选 `Erase Sectors`、`Program`、`Verify` 和 `Reset and Run`。
11. Programming Algorithm 列表中应有 `STM32F10x Medium-density Flash` 或 `STM32F10x_128`。若列表为空，点击 `Add`，选择 STM32F10x 128KB 算法后点击 `Add`，再点击 `Close`。
12. 连续点击 `OK` 保存设置。

Keil 可能自动生成 `GIMBAL.uvoptx`，这是正常的，它保存你电脑上的 ST-Link 选择。

## 五、编译

1. 点击菜单 `Project -> Build Target`，或者按 `F7`。
2. 查看下方 Build Output。
3. 必须看到：

```text
0 Error(s)
```

警告不一定会阻止下载，但出现 Error 必须先解决。成功后会生成：

```text
STM32F103C8T6_Keil工程\OBJ\GIMBAL.hex
```

如果提示找不到 ARM Compiler 5，打开 `Options for Target -> Target -> ARM Compiler`，选择已安装的 Compiler 5；这个验证工程使用 ARMCC 5.06。若 Keil 没有 Compiler 5，需要先在 Keil 中安装 Legacy ARM Compiler 5。

## 六、下载到芯片

1. 确认 ST-Link 已插入电脑，开发板已经获得 3.3V 或自身 5V供电。
2. 点击菜单 `Flash -> Download`，或者按 `F8`。
3. 下方应依次出现类似信息：

```text
Erase Done.
Programming Done.
Verify OK.
Application running ...
```

看到 `Verify OK` 才表示烧录成功。因为已勾选 `Reset and Run`，程序会自动开始运行；也可以按一下开发板 `RST` 按键。

## 七、识别不到芯片时

按顺序检查：

1. DIO 是否接 DIO/PA13，CLK 是否接 CLK/PA14，二者不能交叉。
2. ST-Link GND 是否与开发板 GND 相连。
3. 用万用表确认开发板 3.3V 与 GND 之间确实约为 3.3V。
4. `BOOT0` 保持 0。
5. 在 ST-Link Settings 中把时钟降到 `100 kHz`。
6. 接上 ST-Link 的 NRST 到开发板 NRST，选择 `Connect under Reset`；按住开发板 RST，点击 Download，连接开始后松开 RST。
7. 关闭可能占用 ST-Link 的 STM32CubeProgrammer、ST-Link Utility 或另一个 Keil 窗口。

## 八、烧录完成后恢复整机连接

1. 关闭开发板和 24V 电机电源。
2. 可以保留 ST-Link 的 DIO/CLK/GND，但不要同时用 ST-Link 3.3V 和其他电源给板子供电。
3. 连接 USB-TTL：TXD 接 PA10，RXD 接 PA9（可不接），GND 接 STM32 GND。
4. 接好两台驱动器的 COM、EN、STP、DIR 和 GND。
5. 先给 STM32 上电，再打开 24V 电机电源。
6. 先按一个实体按键测试，再运行电脑端 `pc_keyboard.py`。
