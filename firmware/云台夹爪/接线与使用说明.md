# STM32F103C8T6 二维步进云台接线与使用

本方案采用手册中的共阳脉冲控制：STM32 向两个云台 EMM42 输出 `EN`、`STP`、`DIR`；夹爪则使用 USART1 的 TTL 串口接收指令。

## 1. 下方电机（左右）

| EMM42 端子 | STM32F103C8T6 |
|---|---|
| COM | 3.3V |
| GND | GND |
| EN | PB0 |
| STP | PB1 |
| DIR | PB10 |

## 2. 上方电机（上下）

| EMM42 端子 | STM32F103C8T6 |
|---|---|
| COM | 3.3V |
| GND | GND |
| EN | PB3 |
| STP | PB5 |
| DIR | PB4 |

这是共阳接法：两个驱动器的 `COM` 都接 STM32 的 `3.3V`，`GND` 都接 STM32 的 `GND`。不要把 COM 接到 24V。

## 3. 四个按键

| 按键 | STM32 引脚 | 按键另一端 |
|---|---|---|
| 左 | PB12 | 3.3V |
| 右 | PB13 | 3.3V |
| 上 | PB14 | 3.3V |
| 下 | PB15 | 3.3V |

当前硬件实测为按下高电平、释放低电平。程序使用 STM32 内部下拉，按键不需要外接下拉电阻。按住不会连续移动，松开后再次按下才会再移动一次。

## 4. 夹爪的两个按键

夹爪按键也是按下高电平、释放低电平，每个按键一端接 STM32 引脚，另一端接 3.3V：

| 按键 | STM32 引脚 | 按键另一端 |
|---|---|---|
| 开夹 | PA8 | 3.3V |
| 关夹 | PB11 | 3.3V |

程序使用内部上拉，不需要外接电阻；按住不会重复发送。

## 5. 电脑 USB-TTL 与夹爪串口

| USB-TTL | STM32F103C8T6 |
|---|---|
| TXD | PA10（USART1_RX） |
| RXD | PA9（USART1_TX，可不接） |
| GND | GND |

使用 3.3V TTL 电平，波特率为 115200、8N1。电脑只向 STM32 发命令时，USB-TTL 的 RXD 可以不接。不要使用正负电压的 RS232 转换器。

夹爪使用同一组 USART1 TTL 信号接收 C6 指令。程序发送速度为 180.0 RPM，电流限制为 2000mA：

| STM32 | 夹爪驱动器端子 |
|---|---|
| PA9（USART1_TX） | RX（TTL 模式） |
| PA10（USART1_RX） | TX（可不接） |
| GND | GND |

电脑 USB-TTL 的 TXD 接 PA10，RXD 接 PA9；STM32 发出的夹爪指令同时可被电脑监视。夹爪 TX 和 USB-TTL TX 不要同时接 PA10，避免发送端冲突；本程序不读取夹爪回复，因此夹爪 TX 可悬空。夹爪默认地址为 `1`、波特率 `115200`，程序使用固定校验字节 `0x6B`。

夹爪驱动器屏幕中请打开堵转保护 `Clog_Pro=Enable`。建议初始参数为：`Clog_Rpm=8 RPM`、`Clog_Ma=1800mA`、`Clog_Ms=1000ms`；如果电机铭牌额定电流不同，`Clog_Ma` 和程序中的 `GRIPPER_CURRENT_MA` 必须按额定电流调整，不能超过额定值。堵转保护触发后驱动器应停止输出，用于夹到硬物和到达开/闭限位时保护电机。

夹爪开合是到端点的动作，不是固定毫米数。程序记录最近一次发出的目标状态：已经开时再次按开夹不会重复发送，已经关时再次按关夹不会重复发送；上电后第一次开/关命令仍会发送，因为程序无法读取夹爪当前实际位置。

## 6. 电机、夹爪和电源

若电机和驱动板是分离的，电机四线接驱动器的 `A+、A-、B+、B-`；如果是一体式电机，保持厂家原接线。

两个驱动器使用独立于 STM32 的电机电源：

```text
24V 电源正极 -> 两个驱动器的 V+
24V 电源负极 -> 两个驱动器的电源 GND/V-
```

推荐 24V、6A 或更大的稳压直流电源。厂家脉冲接线图标注单台使用 12-32V、3A 以上，因此两台同时工作需按至少 6A 留量。绝不能把 24V 接入 STM32 的 5V、3.3V 或 IO。

夹爪驱动器的 `V+` 接 24V 正极，`GND` 接 24V 负极。夹爪要求 10-29V、3A 以上，建议与云台共用 24V 电源但单独走线；三者可能同时动作时，电源建议至少 9A 并留有余量。夹爪信号 GND、两台 EMM42 信号 GND、STM32 GND 和 USB-TTL GND 要共地，但大电流回路必须直接回到 24V 电源，不能经过 STM32 或洞洞板细地线。

STM32 开发板用单独的稳定 5V 电源供电，例如 USB 5V。必须把以下地线连接在一起：

```text
24V 电源负极
下方驱动器 GND
上方驱动器 GND
STM32 GND
USB-TTL GND
```

电机大电流电源线应直接回到 24V 电源，不能让电机电流经过 STM32 板或洞洞板的细地线。断电后才能插拔电机线。

## 6. 编译和使用

Keil 中选择 `STM32F103C8T6`，使用中容量启动文件 `startup_stm32f10x_md.s`，工程预处理宏应包含 `STM32F10X_MD` 和 `USE_STDPERIPH_DRIVER`。将 `main.c` 加入标准外设库工程后编译并用 ST-Link 下载。

电脑安装 pyserial 后运行：

```text
python -m pip install pyserial
python pc_keyboard.py COM3
```

将 `COM3` 换成实际串口号。电脑方向键与四个实体按键功能相同；按 `O` 开夹，按 `C` 关夹。

默认 `MOVE_PULSES=18`：1.8 度电机、16 细分、无减速机构时约为 2.025 度。若云台有减速比，或者驱动器细分不是 16，需要修改该数值。若方向相反，把 `LOWER_REVERSE` 或 `UPPER_REVERSE` 从 `0` 改为 `1`。
